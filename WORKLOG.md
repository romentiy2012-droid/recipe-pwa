## 2026-10-28 — v4: готовка, покупки и сохранность
- Добавлены режим «Готовлю», пошаговый просмотр и отметки ингредиентов.
- Структурированные ингредиенты, целые порции и пересчёт без изменения исходного рецепта; поддержка запятой и дробей. Старые строки сохраняются, неизвестное исходное число порций приложение не угадывает.
- Постоянный список покупок из нескольких блюд; объединение совместимых единиц, сохранение отметок, удаление купленного.
- Автосохранение одного черновика в IndexedDB с фото и незавершённым вводом; восстановление после перезагрузки и явное удаление при отказе сохранять.
- Корзина для обычного и массового удаления; восстановление, отдельное подтверждение окончательного удаления.
- Отправка текста через системное меню, буфер обмена или окно ручного копирования.
- Дата подготовки экспорта и напоминание внутри приложения через 7 дней; формат v2 включает корзину и покупки, импорт совместим с v1 и v2.
- IndexedDB v3 добавляет только хранилище settings; service worker/cache v4 включает kitchen.js.
- Защита от двойной отправки формы и сохранения во время обработки фото; предотвращено дублирование корзины при импорте.

### Проверки
- `node --check` для app.js, kitchen.js, sw.js и браузерного теста; `git diff --check`.
- 5 тестов чистой логики: дроби/валидация, старые строки, порции, покупки/единицы, текст отправки — прошли.
- Браузерные проверки Chromium на экранах 393 и 320 px: обновление базы v2 → v3, редактирование старого рецепта с сохранением избранного, пересчёт, шаги и галочки, сохранение покупок, черновик после перезагрузки (включая фото и незавершённую дробь), корзина/восстановление/окончательное удаление, mocked native share, JSON download, напоминание, импорт v1/v2 в чистую базу, повторный импорт с корзиной, безопасное отображение HTML в названии, отсутствие горизонтального переполнения форм, офлайн-перезапуск с service worker — прошли, необработанных ошибок страницы нет.

## 2026-10-28 — v5: книга, меню, импорт и облачные клиенты
- Добавлены теги/фильтрация, сортировка, личные заметки, источник и двустороннее отображение связей между рецептами.
- Планировщик по неделям, дням и приёмам пищи; покупки из меню с учётом порций, сохранение удалений записей меню.
- «Холодильник» показывает совпавшие и недостающие ингредиенты в локальных рецептах.
- Импорт JSON-LD Recipe (@graph, HowToSection/HowToStep) и microdata; прямое чтение разрешающих CORS сайтов, настраиваемый Worker, вставка HTML/текста, редактор перед сохранением. Ссылка-источник сохраняется, фото обрабатываются отдельно.
- Серверный обработчик Cloudflare Workers и адаптер Vercel готовы к развёртыванию: origin, список доменов, проверка каждого redirect, таймауты, ограничение размера, кодировки страниц. Без настроенного endpoint нельзя обещать импорт с CORS-закрытых сайтов.
- Настоящий PDF одного рецепта/всей активной книги, кириллица, фотографии и заметки. jsPDF 4.2.1 и подмножество DejaVu Sans поставляются локально с лицензиями.
- Клиенты Google Drive appDataFolder (GIS) и Dropbox App folder (PKCE S256, state, срок входа). Публичные client IDs задаются в GUI или config.js. В репозитории нет токенов/секретов.
- Синхронизация по кнопке: снимок каждого устройства, UUID и ревизии, отдельные копии при одновременных правках, tombstones окончательного удаления, локальное восстановление до последней синхронизации. Меню объединяется по ID/дате; список покупок — последний по времени.
- JSON v3 сохраняет новые поля/меню; импорт v1/v2 совместим. Web Share Target для поддерживающих браузеров и входная ссылка recipe_url; ограничения iPhone описаны в SETUP.md.
- Service worker/cache v5 включает локальные модули и ресурсы PDF.
