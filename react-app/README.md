# Мои рецепты — миграция на React

Это **новая реализация интерфейса** на React 19, Vite, Tailwind CSS 4 и компонентах по архитектуре shadcn/ui (Button, Card). Она находится в `react-app/` и **не заменяет существующее приложение в корне репозитория**.

## Запуск
Нужен Node.js 22 (или версия, удовлетворяющая требованиям Vite).

```bash
cd react-app
npm install
npm run dev
npm run build
```

Vite пишет результат в корневую папку `react/` (base: `/recipe-pwa/react/`). После проверки сборки можно публиковать отдельно от старого приложения.

## Реализовано
- React-компоненты, Tailwind CSS v4, конфигурация shadcn/ui, локальные Button и Card
- Чтение и изменение существующих рецептов в IndexedDB `recipeDB` версии 3
- Каталог, поиск, категории, избранное, создание/редактирование рецептов
- Фото, ингредиенты, шаги, заметки, план на неделю, список покупок, резервный экспорт JSON
- Мобильная навигация

## Что пока НЕ перенесено
- Полный импорт/экспорт v1-v3 с поддержкой корзины и конфликтных копий
- Настройки Google Drive/Dropbox и синхронизация
- Импорт Schema.org и Web Share Target
- PDF-книга, холодильник, готовка по шагам, пересчёт порций
- Полная система черновиков и восстановления
- Существующий планировщик и список покупок приложения: новая версия хранит их отдельно в localStorage, а не через прежний модуль Book

**Важно:** не переводить главную ссылку на React до переноса этих возможностей, резервного экспорта из старого приложения и успешного тестирования миграции на iPhone. В одном origin IndexedDB доступна обеим версиям при одинаковой схеме. На другом домене или origin данные не появятся автоматически.

## Проверка
Workflow `.github/workflows/react-check.yml` запускает `npm run build` на GitHub Actions. Пока CI не прошёл, сборка не считается подтверждённой.
